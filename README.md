# Flooring Pro Qatar — starter app

This is an initial cross-platform React Native / Expo starter project for Android and iOS.

## Included in this first development build
- English, Arabic and Bangla language selector
- Six product categories
- Room area calculator with 5%, 10% and 15% material allowance
- Quote request form
- WhatsApp handoff to +974 55802749
- No public prices: customers request a quotation

## Run locally
1. Install Node.js (LTS) and a code editor.
2. In this folder run: `npm install`
3. Run: `npx expo start`
4. Scan the QR code using Expo Go on your phone.
5. For native store builds, configure EAS Build and create Apple Developer / Google Play Console accounts.

## Important before launch
This is a starter implementation, not a published or store-approved app. It currently opens WhatsApp with a prefilled message; it does not store orders in a cloud database or include a secure admin dashboard. Those should be added and tested before public launch. Arabic translation and right-to-left layout need native-device QA. Add your approved logo, product photos, privacy policy, terms, and business details before release.
